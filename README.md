# SABR Model Playground

This repository contains an interactive Jupyter Notebook, `SABR Brief.ipynb`, for exploring the SABR volatility model.

The notebook provides:
- An introduction to the SABR model parameters (`alpha`, `beta`, `rho`, `nu`).
- Visualizations of how each parameter affects the volatility smile.
- An interactive 3D plot of the SABR implied volatility surface.
- Explanations of stochastic volatility and model calibration concepts.


## Requirements

numpy
matplotlib
ipywidgets
scipy
